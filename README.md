# Fashion commerce interface study

This project recreates the responsive structure and interaction patterns of the observed Stüssy homepage without bundling the source site's protected imagery, wordmark, or font files.

## Run

```powershell
npm start
```

Then open `http://localhost:4173`.

See `images/README.md` for the exact replacement asset filenames. The page uses the local system Helvetica Neue stack and falls back to Helvetica/Arial.
